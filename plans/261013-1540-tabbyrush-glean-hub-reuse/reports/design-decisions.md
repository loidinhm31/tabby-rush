Missing mode remains legacy;strict mode cannot downgrade. Existing registration/update callers stay valid;isolated strict path uses real new behavior,not obsolete compatibility shims. Existing engine DTOs/clients/admin UI unchanged.
New admin `/strict-apps` avoids oldbinary silent legacy registration;read-back mode/epoch still mandatory. Intrinsic `_id=userId:rowId`,ordinary simple-collation/noTTL collection and exact scan index verified before registry publication/admission. Every request reads active registry epoch before namespace access;only admission cached. New legacy-only router guard rejects strict/unknown modes;old apps absentmode unchanged. Existing sync service/purge/job/coreclient files need no changes;namespace isolation verified by real bypass gates.

Stable rowId scans include permanent canonical-empty tombstones;staging only complete scans,retain higher confirmed revision and post-scan-start acknowledgements. Same-epoch previously known missing identity pauses inconsistency/reset,not deletion/recreation. Full scans eventual after quiescence,not snapshots. Epoch isolation prevents old requests touching fresh namespace;old-namespace late commit remains possible.
