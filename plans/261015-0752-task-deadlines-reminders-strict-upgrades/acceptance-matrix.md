## Security and release cross-checks
- AC04 app-scoped admin and AC11 account wipe are release blockers. Legacy-receipt route scopes user/app and cannot mutate legacy task payloads.
- Manifest merged release receiver/permission/export/backup hardening; generic Android public lock-screen text and escaped Linux/Windows content.
- Normal dependency verification, target-isolated packages and artifact signing requirements; diagnostic verification-off/source scans insufficient for release.
- Existing-data protection includes drafts, uncertain successor FIFO and revisions, not only server task counts.
- No timing/exactly-once guarantee; no macOS/iOS, recurring tasks, snooze, FCM, desktop daemon/tray or arbitrary-schema feature.
